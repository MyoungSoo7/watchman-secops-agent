# NAT eval — 실알림 50건 재생 KPI (2026-09-25)

`nat_watchman` 플러그인(NeMo Agent Toolkit 1.9.0)으로 운영 에이전트를 감싸 `nat eval` + 프로파일러로 잰 결과다.
데이터는 `real-alerts-20260924.md` 와 같은 블라인드 라벨 50건(정상 37 · 실장애 13, 불명 1건 제외)이다.
알림 원문은 운영 감사로그에서 뽑았고, 도구는 실 클러스터를 읽기 전용으로 부른다. LLM 은 실 NIM 이다.
토큰은 NIM 응답의 `usage` 합이고 시간은 벽시계다. 추정치는 없다.

재생 시점에는 이미 복구되어 있었다. 에이전트는 *지금* 클러스터를 조사하고 "정상이다" 라는 올바른 관측을 했다.
그래서 판정이 오탐으로 떨어졌다. partial 3건은 재생 중 NIM 오류다. Super 가 503 을 냈고, Ultra 폴백까지 끝나지 않았다.
운영에서는 같은 13건이 모두 '사고' 였다(`real-alerts-20260924.md`).

→ **다음 과제:** 알림 시점 증거 스냅샷을 만든다. 도구 응답을 알림 시각 기준으로 녹화해 두었다가 재생 때 되돌려 준다.
그러면 NAT eval 이 시점과 무관한 결정적 평가가 된다. 그 전까지 실장애 recall 은 운영 판정으로 보고한다.
